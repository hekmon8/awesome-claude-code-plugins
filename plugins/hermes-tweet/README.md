# Hermes Tweet

Source: https://github.com/Xquik-dev/hermes-tweet

Hermes Tweet is a native Hermes Agent plugin for X/Twitter research, tweet reading, trend checks, and approval-gated social actions through Xquik.

## Features

- X/Twitter search and timeline exploration
- Tweet and reply reading
- Trend checks and social context gathering
- Approval-gated action tools

## Install

Install from the source repository:

```bash
pip install hermes-tweet
```

Then follow the source README for Hermes Agent plugin registration and `XQUIK_API_KEY` setup.
